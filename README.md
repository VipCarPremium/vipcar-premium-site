# VipCar Premium — publicar no GitHub Pages

1. Crie um repositório público chamado vipcar-premium-site na sua conta GitHub.
2. Extraia este ZIP no computador.
3. Em Add file > Upload files, envie os arquivos extraídos e a pasta assets. Não envie o ZIP. O index.html precisa ficar na raiz do repositório.
4. Confirme o envio em Commit changes.
5. Abra Settings > Pages. Em Source, selecione Deploy from a branch.
6. Escolha main e /(root), depois Save.
7. Aguarde a publicação. O endereço aparecerá em Settings > Pages.

Se a conta for vipcarpremium, o endereço será https://vipcarpremium.github.io/vipcar-premium-site/

## Editar
- index.html: textos, planos, contatos e links da página inicial.
- aplicativo.html: instruções de instalação do aplicativo.
- style.css: cores, aparência e adaptação às telas.
- script.js: interações da página.
- assets/: imagens e logo.

Abra o arquivo no GitHub, clique no lápis, edite e use Commit changes. O GitHub Pages publica as alterações automaticamente.

## Editar com outro chat ou conta
Forneça o link do repositório e descreva as mudanças. Se o assistente não tiver acesso ao código, envie este ZIP ou uma cópia atualizada obtida em Code > Download ZIP. Para publicar mudanças, use a conta GitHub proprietária ou conceda acesso a um colaborador.

O site é estático e não precisa de instalação de dependências. Os botões abrem as plataformas externas existentes. As senhas são digitadas nessas plataformas.
